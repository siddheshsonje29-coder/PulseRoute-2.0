PLATFORM INTEGRITY

Trust & Security by Design

PulseRoute enforces strict architectural security protocols to ensure reliable handling of emergency operations.

🔒

Secure Authentication

All citizen and hospital credentials utilize salted BCrypt hashing. Sessions are maintained via secure HTTP-only cookies with configurable expiration.

🛡️

Role-Based Access Control

Strict isolation enforced at the Jakarta WebFilter layer prevents unauthorized access between citizen telemetry, hospital triage, and fleet assignment.

⚡

Protected Dashboards

Unauthenticated requests attempting to access protected dashboards are automatically trapped and redirected to the login portal with origin preservation.
